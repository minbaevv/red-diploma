# Changelog

Краткая история заметных изменений проекта «Red Diploma».

## J.A.R.V.I.S.

### Голосовое управление без рук

- Приветствие «привет, Джарвис» (RU) и «салам, Джарвис» (KG) запускает распознавание речи.
- Захват идёт до паузы ~1.4 с, поэтому фраза попадает в обработку целиком, а не первым промежуточным результатом.
- Разрешение на микрофон запрашивается через `getUserMedia` до старта `SpeechRecognition`: Chrome умеет отдавать `not-allowed`, пока его собственный запрос ещё открыт.
- Автоподстановка слушателей сохраняется на всё время жизни страницы; повторная попытка включается по клику, клавише и событию `Permissions API`.
- «пока, Джарвис» и «отключись» отвечают «До связи, сэр.» и возвращают помощника в режим ожидания, поэтому следующее приветствие снова срабатывает.
- Статусы в интерфейсе: «включаю микрофон…», «слушаю вас», «слушаю „Джарвис“», «микрофон выключен».

### Свободные вопросы

- Общие вопросы («что такое list comprehension», «как работает dict») уходят в поиск по темам и в локальную модель Ollama.
- Объяснение, подсказка и разбор задачи остаются локальными и не тратят запрос к модели.
- Для русских вопросов учитываются только сильные совпадения по заголовкам тем; слабые передаются модели.
- Локальная модель — `qwen2.5:3b`; качество фактов растёт с размером модели через `OLLAMA_MODEL`.
- Кыргызские ответы остаются на детерминированном локальном движке.

### Ограничения

- Решения задач и скрытые тесты не выдаются ни в одном режиме.
- Голоса Piper привязаны к языку: `ru_RU-dmitri-medium` для русского, `en_GB-jarvis-high` для английского, браузерный синтез для кыргызского.

## Контент

- Два маршрута: `ml-capstone` (5 разделов, 20 шагов) и `exam-project` (6 разделов, 12 шагов, только практика).
- 152 задачи, из них 54 с кодом; у каждой есть разбор, типичные ошибки и экзаменационный совет.
- 206 вопросов в тренажёре по 8 категориям.
- В практике клиенту отдаются только первые два теста как примеры; остальные тесты и решение остаются на сервере.

## Тесты

- `pytest`: 42 теста, включая маршрутизацию J.A.R.V.I.S., проверки контента и изоляцию базы через `backend/tests/conftest.py`.
- `npm run build` собирает фронтенд без ошибок.
